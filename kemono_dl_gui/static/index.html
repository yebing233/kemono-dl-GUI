命令行选项对照

CLI 选项说明GUI 位置
--path下载根目录保存位置 → 下载目录
--output输出路径模板（可带 attachments:/content:/json: 前缀）命名模板
--batch-file从文本文件读取链接链接 → 批次文件
--cookiescookies 文件（可多个）账号 → Cookies 文件
--favorite-creators-kemono -coomer -pawchive下载收藏创作者链接 → 收藏创作者
--kemono-login --coomer-login --pawchive-login用户名 + 密码登录账号 → 登录
--restrict-names文件名限制为 ASCII保存位置 → 限制为 ASCII 文件名
--custom-template-variables自定义模板变量 JSON命名模板 → 自定义模板变量
--date --datebefore --dateafter按 added/edited/published 过滤日期过滤 → 日期过滤
--skip-extensions跳过的扩展名列表过滤 → 跳过的扩展名
--skip-attachments不下载附件过滤 → 跳过附件
--write-content保存帖子正文 HTML保存位置 → 保存帖子正文
--write-json保存帖子 API JSON保存位置 → 保存帖子 JSON
--no-tmp不产生 .tmp 临时文件保存位置 → 不使用 .tmp
--archive已下载帖子归档文件过滤 → 归档文件
--version打印版本号左侧栏版本徽标 / 本面板

GUI 不重新实现下载逻辑：每次运行都会以 python -m kemono_dl … 启动真实 CLI，参数与上表一一对应，因此行为与命令行完全一致。

本地服务仅监听 127.0.0.1，并校验会话令牌。
